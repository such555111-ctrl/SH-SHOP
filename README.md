# SH SHOP — Telegram Mini App

Витрина **SH SHOP** («Всё для пара», «Лучшие цены») в виде Telegram-бота с мини-приложением:
каталог, избранное, корзина, промокоды, оформление заказа, профиль с историей заказов и админ-панель.
Заказ уходит менеджеру (@SHvape_manager), онлайн-оплата не подключена.

## Состав
```
main.py           — Flask-сервер: мини-апп, Telegram-бот (webhook), API админки
index.html        — интерфейс мини-приложения (18+ гейт, hero, каталог, корзина, заказ)
admin.html        — админ-панель (товары, заказы, вопросы, промокоды)
products.json     — каталог SH SHOP (82 позиции из прайса канала)
brand/            — sh-logo.svg/png, sh-avatar.png (512×512), sh-banner.png (1280×640)
requirements.txt, Procfile, render.yaml — запуск на Render
```

## Фирменный стиль
| Что | Значение |
| --- | --- |
| Фон | `#07080F` (чёрно-синий), карточки `#0E1220` |
| Основной акцент | огонь `#FFA51E` → `#FF5A1F` (градиент кнопок, фильтров, ленты) |
| Золото (цены, «Хит», корона) | `#FFC21A` |
| Электро-синий (бейдж «В тренде», свечение) | `#3B8CFF` |
| Шрифты | Unbounded (заголовок и логотипные акценты), Montserrat (заголовки/кнопки), Inter (текст) |

Цвета и шрифты — переменные в начале `<style>` в `index.html` и `admin.html` (`:root{…}`).
Логотип вшит как SVG-спрайт `#sh-logo`; файлы для аватарки бота/канала — в `brand/`.

## Запуск (Render)
1. @BotFather → `/newbot`, затем `/setuserpic` → `brand/sh-avatar.png`.
2. Загрузите файлы в корень GitHub-репозитория, на Render создайте Web Service.
   Build: `pip install -r requirements.txt`, Start: `gunicorn main:app --bind 0.0.0.0:$PORT`.
3. Переменные окружения: `BOT_TOKEN`, `ADMIN_PASSWORD`, `ADMIN_CHAT_ID` (ваш Telegram ID, можно несколько через запятую),
   `SHOP_CONTACT` (по умолчанию `SHvape_manager`), `WEBHOOK_URL` (необязательно).
4. `/start` в боте → «🚀 Открыть SH SHOP». Админка: `https://ваш-адрес.onrender.com/admin`.

## Что заполнить после запуска
- Фото товаров, реальные вкусы/цвета и описания — через `/admin` (сейчас у позиций «Вкус / цвет — по согласованию» и цветные плашки).
- Бейджи («Хит», «Скидка» и т.д.) — в админке; сейчас «Хит» только у жидкости «Монашка».
- Номера заказов имеют вид `SH-12`.

> Постоянное хранилище: на бесплатном плане Render файлы (`products.json`, `orders.json`, `uploads/`) не сохраняются
> между рестартами — для постоянной работы подключите Persistent Disk (см. `render.yaml`).
> Проверьте требования законодательства вашего региона к продаже и дистанционной торговле никотиносодержащей продукцией.
